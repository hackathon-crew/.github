# 黑客松

欢迎来到 **hackathon-crew**。

我们是一群喜欢把想法做出来的人，想和更多朋友一起参加黑客松、做项目、解决真实问题，也在一次次尝试和复盘里共同进步。

无论你擅长开发、设计、产品、研究、写作，还是愿意负责沟通和现场表达，都欢迎加入我们。一个还不成熟的想法、一项正在学习的技能，或者一颗愿意一起动手的心，都可以成为合作的起点。

## 我们一起做什么

- 组队参加黑客松和创新类比赛
- 从想法出发，快速做出可以演示的产品
- 分享工具、经验和踩坑记录
- 在合作中学习，在复盘中进步

## 关于我

我目前在 **华中师范大学**。这个团队也从校园里的尝试开始，希望把每一次比赛都变成认识伙伴、打磨能力和把事情做成的机会。

## 目前的项目

- [Contest Detective](https://github.com/hackathon-crew/contest-detective)：帮助大家发现、筛选和核实黑客松及其他比赛信息
- [Windup](https://github.com/1024XEngineer/Windup)：面向国产小游戏开发者的 2D 角色动态素材生成与资产工作台
- [群学致知](https://github.com/huyanxius/qunxue)：面向社会学入门者和初级研究者的理论发现与研究设计工作台

## 加入我们

如果你也想一起打黑客松、做点有意思的东西，欢迎在本组织的仓库里提交 Issue，介绍一下你感兴趣的方向和想一起做的事情。期待和你认识，一起开工。
